## Music data

| Source | Terms | Use |
|---|---|---|
| [iTunes Search API](https://performance-partners.apple.com/search-api) | Apple's Search API terms; public, no key | Search, album and artist lookups, artwork and 30-second previews, served from Apple's CDN |
| [Apple Music RSS feeds](https://rss.marketingtools.apple.com) | Apple's terms; public, no key | The weekly most-played charts in 12 countries behind `src/data/tracks.ts` |
| [Deezer API](https://developers.deezer.com/api) | Deezer's API terms; public, no key | "Where it plays": matching recordings on Deezer, each linking to Deezer |

Song data, artwork and previews belong to their owners and are not covered by Lowband's MIT licence.
